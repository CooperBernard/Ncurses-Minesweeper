# Ncurses-Minesweeper
Terminal-based Minesweeper using Ncurses

This program requires a terminal window to run successfully. I recommend executing the program in bash.

Ensure that you have installed the Ncurses library. To compile, run the "make" command. To run the program, run the executable "minesweeper".

Controls:
Arrow keys to move cursor. The cursor will wrap in all directions.
F key to place/remove flag.
Spacebar to reveal current tile. If a numbered tile has all flags satisfied, click the number tile to reveal all adjacent tiles.
Ctrl+C to exit program
